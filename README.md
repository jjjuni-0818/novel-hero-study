# 💌 당신의 웹소설 남주는? — AI 남주와 함께하는 Study with Me

> 웹소설 남주 유형 테스트 + 포모도로 타이머 + AI 캐릭터 대화

🔗 **[Live Demo](https://jjjuni-0818.github.io/novel-hero-study/)**

---

## 기획 배경

네이버 웹소설·웹툰을 매일 2회 이상 소비하는 여성향 콘텐츠 헤비 유저로서, 로맨스 장르에 대한 높은 몰입도를 갖고 있다.

인스타그램 피드에서 AI 캐릭터 채팅 서비스에 대한 관심이 급증하는 트렌드를 관찰하며, 평소 좋아하던 웹소설 남주 캐릭터와 실제로 대화할 수 있는 서비스에 흥미를 갖게 됐다. 여기서 한 발 더 나아가 "좋아하는 캐릭터가 공부하는 동안 옆에 있어준다면 더 재밌지 않을까"라는 아이디어로 확장, 여성향 콘텐츠 소비 패턴과 생산성 툴을 결합한 서비스 가능성을 직접 검증하고자 제작했다.

---

## 서비스 흐름

```
[1단계] 남주 유형 테스트
  - 공부 스타일, 선호 남주 유형, 위로 방식, 집중 시간, 선호 분위기 등 5문항
  - 각 선택지에 A/B/C/D 가중치 부여 → 합산 점수로 캐릭터 매칭

        ↓

[2단계] 캐릭터 매칭 결과
  - 🥀 냉혹한 재벌 (츤데레) / 🌸 따뜻한 소꿉친구
  - 👑 카리스마 황제 / 🌙 4차원 천재
  - 캐릭터 설명 + 태그 표시 → 감정적 연결감 강화

        ↓

[3단계] Study with Me 타이머
  - 포모도로 기법 (집중 25분 / 휴식 5분) 자동 전환
  - 타이머 구간별 캐릭터 고유 대사 노출 (집중 독려 / 휴식 안내)
  - 5분마다 새 대사로 교체 → 단조로움 방지
  - 완료 세션 카운트로 성취감 제공

        ↓

[4단계] AI 캐릭터 대화
  - Groq API (llama-3.1-8b-instant) + 캐릭터별 시스템 프롬프트
  - 캐릭터 말투·감정 표현·반응 방식을 프롬프트로 정의해 페르소나 일관성 유지
  - 대화 히스토리 8턴 유지로 맥락 있는 대화 구현
  - API 키 미입력 시 프리셋 대사 폴백 처리
```

---

## 주요 기능

- **남주 유형 테스트** — 가중치 기반 점수 합산으로 4가지 캐릭터 중 매칭
- **포모도로 타이머** — SVG 링 애니메이션, 자동 모드 전환, 세션 카운트
- **AI 캐릭터 대화** — 캐릭터별 독립 시스템 프롬프트로 말투·감정 차별화
- **폴백 처리** — API 키 없이도 프리셋 대사로 동작, 키워드 감지 기반 응답

---

## 기술 스택

| 구분 | 내용 |
|------|------|
| Frontend | Vanilla HTML / CSS / JavaScript (단일 파일) |
| AI | Groq API (llama-3.1-8b-instant) |
| 배포 | GitHub Pages |

백엔드 없이 단일 HTML 파일로 구성. 사용자가 직접 Groq API 키를 입력하는 방식으로 서버 없이 AI 대화 구현.

---

## 로컬 실행

```bash
# 별도 설치 없이 index.html을 브라우저에서 바로 열기
open index.html
```

AI 대화 기능 사용 시 [Groq 콘솔](https://console.groq.com/keys)에서 무료 API 키 발급 후 앱 내 입력란에 입력.
